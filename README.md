# خطوة الشهر

تطبيق عربي HTML/CSS/JavaScript لإدارة المصروفات والسيولة ودورة البطاقات. لا يحتاج تثبيت حزم أو خادم بيانات. البيانات محفوظة في localStorage، والنسخ الاحتياطي JSON من الإعدادات.

## التشغيل

شغّل داخل المجلد `python3 -m http.server 8000` ثم افتح `http://localhost:8000`. فتح index.html مباشرة من الملفات لا يدعم وحدات JavaScript وService Worker في بعض المتصفحات.

راجع الإعدادات قبل البداية: سعر الدولار الافتراضي 50 مجرد قيمة قابلة للتعديل وليس سعرًا مباشرًا. أكد الديون الافتتاحية، مواعيد السداد، القسط، وفترة الانتظار. سجّل الدخل عندما تستلمه، ثم اتبع مرشد الشهر.

## النشر على GitHub Pages

1. أنشئ مستودع GitHub وارفع **محتويات هذا المجلد** إلى جذر المستودع، بما فيها icons وملف .nojekyll.
2. افتح Settings → Pages → Deploy from a branch، واختر main و / (root)، ثم Save.
3. افتح الرابط الذي يعرضه GitHub Pages بعد اكتمال النشر. المسارات نسبية وتدعم `https://USERNAME.github.io/REPOSITORY/`.
4. افتح الموقع متصلًا بالإنترنت مرة واحدة، ثم ثبته من قائمة المتصفح على أندرويد أو من مشاركة → إضافة إلى الشاشة الرئيسية على Safari في آيفون.

GitHub Pages يحتاج HTTPS لتشغيل PWA. بيانات كل متصفح وجهاز مستقلة. تغيير عنوان الموقع لا ينقل localStorage؛ صدّر النسخة من العنوان القديم واستوردها في الجديد. الأرقام الافتراضية موجودة في المصدر؛ استخدم مستودعًا خاصًا إذا كانت خطة GitHub لديك تدعم Pages الخاص وتريد إخفاء المصدر، أو غيّر الأرقام الافتراضية قبل نشر مستودع عام.

## تسجيل العمليات

- الأكل محجوز وليس مدفوعًا؛ كل مصروف أكل يقلل الرصيد والمحجوز معًا.
- رسوم السداد حقل إلزامي؛ أدخل صفرًا إذا لا توجد رسوم.
- السحب يخصم المبلغ الكامل من البطاقة ويضيف صافي الكاش إلى الرصيد. حد العملية 10000 جنيه، ورسوم فوري الافتراضية 1%.
- تعديل وحذف الحركات يعيد الحساب. راجع الشهر التالي إذا عدلت شهرًا أقدم؛ رصيد افتتاح الشهر التالي لقطة وقت إنشائه ولا يتغير تلقائيًا.
- فتح شهر جديد يرحّل الرصيد والالتزامات غير المدفوعة فوق ميزانية الشهر المعتادة. يمكنك تعديل المبلغ قبل اعتماد الشهر. قسط NBK A غير المدفوع يرحّل ويضاف للالتزام التالي. ميزانية الكريديت تتجدد دون مضاعفة أصل دين البطاقات؛ الدين نفسه مستمر.
- المعادلات تتبع العمليات التي تسجلها؛ البنك هو مرجع المديونية الفعلية والفوائد وإتاحة السحب.

## الاختبارات

`node --test tests.mjs`

يشمل الاختبار حجز الأكل، السداد والسحب الجزئي، الرسوم، تأخر الدخل، الانتظار، تغيير سعر الصرف، النسخ الاحتياطي، وعزل حساب الدين التاريخي عن الشهور اللاحقة. اختبر التثبيت النهائي على موبايلك بعد نشر رابط HTTPS.

عند تحديث ملفات التطبيق غيّر اسم CACHE في sw.js. افتح الموقع متصلًا بالإنترنت وأغلق النوافذ القديمة ليتفعّل إصدار Service Worker الجديد.
